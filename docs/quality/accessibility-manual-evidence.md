This is the repository template for manual evidence. It is not a completed
review and must not be presented as a certification.

One completed record must state what was actually tested, identify any remaining
limitation, and link to the corresponding publication report. A browser engine
test or emulation is not a substitute for recorded branded-browser or physical
device evidence where either is required.
